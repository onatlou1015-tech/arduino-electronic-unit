Bluetooth Module (HC-05 / HC-06)

Learn how serial communication works, pair your Arduino with a smartphone, and control your robot wirelessly.
📸 Upload: HC-05 Bluetooth module wired to the Arduino, paired with a smartphone

Recommended size: 1200 × 400 px · JPG or PNG

1. How Does a Bluetooth Module Work?

The HC-05 and HC-06 are small, low-cost Bluetooth modules that let your Arduino talk to a phone, tablet, or computer over short distances (about 10 metres).

They act as a wireless serial bridge: whatever your phone sends over Bluetooth arrives on the Arduino's RX pin, and whatever the Arduino sends out its TX pin is broadcast back to your phone.

From the Arduino's perspective, it's exactly like using the USB cable — except now the data is coming from the air instead. 📡

Wireless Serial

Sends and receives text data wirelessly, just like a serial USB connection.

Pairing

Your phone connects to the module using a PIN code (usually 1234 or 0000).

3.3V Logic

The module runs at 3.3V — voltage dividers are often needed on the RX pin for safety.

2. HC-05 vs HC-06 — What's the Difference?

Both modules work almost identically for basic use. The main difference is that HC-05 can act as both a master and a slave, while HC-06 is slave-only.

HC-05

  • Can be master or slave
  • Supports full AT command set
  • Flexible for advanced projects
  • Default PIN: 1234

HC-06

  • Slave only (most common use)
  • Smaller, simpler, cheaper
  • Perfect for phone-controlled robots
  • Default PIN: 1234 or 0000
For this project: Either module will work. If you're buying new, the HC-05 is more versatile — but the HC-06 is usually a few dollars cheaper and does exactly what we need.
3. Serial Communication: TX / RX

Every serial connection uses two data lines: TX (transmit) and RX (receive). The golden rule is simple:

👉 TX of one device connects to RX of the other — and vice versa.

This "cross-over" wiring is what allows each device to send into the other's receiver.

HC-05/06 Pin Arduino Uno Pin Purpose
VCC 5V Powers the module (HC-05 has an onboard 3.3V regulator).
GND GND Common ground — always required.
TXD RX (pin 0) or SoftwareSerial pin Module sends data → Arduino receives.
RXD TX (pin 1) or SoftwareSerial pin Arduino sends data → module receives.
Warning: The HC-05 RX pin expects 3.3V logic. Sending 5V directly may damage it. Use a voltage divider (two resistors) on the RXD line — or pick a module with a built-in level shifter.
Why SoftwareSerial? Pins 0 and 1 are also used for USB upload. It's cleaner to use SoftwareSerial on pins 2 and 3 so you can still upload code without unplugging the module.
4. Quick Start — Five Simple Steps

Follow these five steps in order before pairing your phone:

  1. Wire the module: VCC → 5V, GND → GND, TXD → Arduino pin 2 (RX), RXD → Arduino pin 3 (TX).
  2. Install a Bluetooth terminal app on your phone (e.g., "Serial Bluetooth Terminal" on Android).
  3. Pair your phone with "HC-05" or "HC-06" using PIN 1234 or 0000.
  4. Open the app and connect to the module — the onboard LED should change from blinking fast to slow (or stop blinking).
  5. Send a test message: Upload the code from section 5, then type "1" in the app — the onboard Arduino LED should turn on.
5. Code — Control an LED from Your Phone

Click Copy and paste this into your Arduino IDE. Type "1" to turn the LED on, "0" to turn it off.

bluetooth_led.ino
/* Bluetooth LED Control — HC-05 / HC-06 Send '1' from a Bluetooth app to turn the LED on. Send '0' to turn it off. */ #include <SoftwareSerial.h> // Bluetooth module on pins 2 (RX) and 3 (TX) SoftwareSerial bluetooth(2, 3); const int ledPin = 13; // Onboard LED void setup() { pinMode(ledPin, OUTPUT); Serial.begin(9600); // USB Serial (for debugging) bluetooth.begin(9600); // Bluetooth Serial Serial.println("Bluetooth ready. Send 1 or 0."); } void loop() { if (bluetooth.available()) { char command = bluetooth.read(); Serial.print("Received: "); Serial.println(command); if (command == '1') { digitalWrite(ledPin, HIGH); bluetooth.println("LED ON"); } else if (command == '0') { digitalWrite(ledPin, LOW); bluetooth.println("LED OFF"); } } }
How it works: The Arduino listens on the bluetooth serial port. When a character arrives, it checks whether it's "1" or "0" and lights the LED accordingly.
6. Code — Drive the Robot from Your Phone

Extend the concept to control both motors. Send F (forward), B (backward), L (left), R (right), or S (stop).

bluetooth_robot.ino
/* Bluetooth Robot Control — HC-05 / HC-06 + L298P Commands: F = forward B = backward L = left R = right S = stop */ #include <SoftwareSerial.h> SoftwareSerial bluetooth(2, 3); // L298P motor control pins const int IN1 = 8; const int IN2 = 9; const int IN3 = 10; const int IN4 = 11; void setup() { pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT); bluetooth.begin(9600); Serial.begin(9600); } void forward() { digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW); digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW); } void backward() { digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH); digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH); } void left() { digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH); digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW); } void right() { digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW); digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH); } void stopMotors() { digitalWrite(IN1, LOW); digitalWrite(IN2, LOW); digitalWrite(IN3, LOW); digitalWrite(IN4, LOW); } void loop() { if (bluetooth.available()) { char cmd = bluetooth.read(); Serial.println(cmd); switch (cmd) { case 'F': forward(); break; case 'B': backward(); break; case 'L': left(); break; case 'R': right(); break; case 'S': stopMotors(); break; } } }
