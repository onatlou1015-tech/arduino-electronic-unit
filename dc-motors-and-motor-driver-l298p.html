DC Motors & Motor Driver (L298P)

Learn how DC motors spin, why the Arduino can't drive them directly, and how the L298P H-bridge lets you control direction and speed.

1. What Is a DC Motor?

A DC motor is an electrical machine that spins when you apply a DC voltage across its two terminals. Reverse the voltage, and the motor spins the other way.

DC motors are everywhere — in robots, drones, electric cars, and even your phone's vibration motor. In your Arduino robot, they're what make the wheels turn. ⚙️

Voltage-Driven

The more voltage you apply, the faster the motor spins (up to its rated limit).

Direction

Swap the + and – wires and the motor reverses — that's how your robot turns.

Current-Hungry

Motors can draw 200 mA to 2 A or more — far more than an Arduino pin can supply.

2. Why Do We Need a Motor Driver?

Each Arduino pin can safely supply only about 20 mA at 5V. A DC motor needs hundreds of milliamps — trying to drive one directly would fry the Arduino. 💥

The L298P motor driver solves this by acting as a bridge between the Arduino's low-power signals and the motor's high-power needs. You send small signals to the driver, and the driver sends big current to the motors.

Rule of thumb: If it has a coil and spins — motors, solenoids, relays — you almost always need a driver.
3. The H-Bridge Concept

Inside the L298P is an H-bridge — a clever circuit of four switches that lets you control a motor's direction without rewiring anything.

Forward

  • Switch 1 & Switch 4 are closed
  • Current flows left → right through the motor
  • Motor spins clockwise

Reverse

  • Switch 2 & Switch 3 are closed
  • Current flows right → left through the motor
  • Motor spins anticlockwise

4. L298P Pinout at a Glance

The L298P module has clearly labelled pins on each side. Here's what you need to know:

Pin Group Names Purpose
Motor Power +12V, GND Battery input (7V–12V). Powers the motors, not the Arduino.
5V Output +5V Onboard regulator — can power the Arduino (jumper must be in place).
Control Inputs IN1, IN2, IN3, IN4 Signals from the Arduino. IN1/IN2 for Motor A, IN3/IN4 for Motor B.
Enable Pins ENA, ENB Speed control via PWM. Remove the jumper to control speed from Arduino.
Motor Outputs OUT1, OUT2, OUT3, OUT4 Connect to the two terminals of Motor A and Motor B.

5. Quick Start — Five Simple Steps

Follow these five steps in order before uploading your code:

  1. Power the L298P: Connect the battery + to +12V and battery – to GND on the driver.
  2. Connect the motors: Wire one motor to OUT1 & OUT2, and the other to OUT3 & OUT4.
  3. Wire the control pins: Arduino D8 → IN1, D9 → IN2, D10 → IN3, D11 → IN4.
  4. Enable speed control: Remove the ENA and ENB jumpers and connect them to Arduino pins 5 and 6 (PWM).
  5. Share ground: Connect the Arduino GND to the L298P GND — this step is essential!
6. Code — Spin Both Motors

Click Copy and paste this into your Arduino IDE. It spins both motors forward, backward, then stops in a loop.

spin_motors.ino
/* Spin Motors — L298P Test Motor A and Motor B spin forward, then reverse, then stop. */ // Control pins for Motor A const int IN1 = 8; const int IN2 = 9; // Control pins for Motor B const int IN3 = 10; const int IN4 = 11; void setup() { pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT); } void loop() { // Forward digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW); digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW); delay(2000); // Reverse digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH); digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH); delay(2000); // Stop digitalWrite(IN1, LOW); digitalWrite(IN2, LOW); digitalWrite(IN3, LOW); digitalWrite(IN4, LOW); delay(1000); }
How it works: Setting IN1 HIGH and IN2 LOW tells the L298P to send current one way through Motor A. Flipping them sends current the other way — reversing the spin.
7. Code — Control Speed with PWM

Use analogWrite() on the ENA/ENB pins to control motor speed from 0 (stop) to 255 (full speed).

motor_speed.ino
/* Motor Speed Control — L298P + PWM Ramps Motor A from slow to fast, then back down. */ const int ENA = 5; // PWM pin for Motor A const int IN1 = 8; const int IN2 = 9; void setup() { pinMode(ENA, OUTPUT); pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); // Set Motor A direction: forward digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW); } void loop() { // Ramp up speed for (int speed = 0; speed <= 255; speed += 5) { analogWrite(ENA, speed); delay(30); } // Ramp down speed for (int speed = 255; speed >= 0; speed -= 5) { analogWrite(ENA, speed); delay(30); } }
