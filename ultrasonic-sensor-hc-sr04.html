Ultrasonic Sensor (HC-SR04)

Learn how sound waves measure distance with time-of-flight, and use the HC-SR04 to give your robot "eyes" for obstacle avoidance.

1. How Does an Ultrasonic Sensor Work?

The HC-SR04 measures distance using sound waves — specifically ultrasonic waves, which are too high-pitched for humans to hear. It works like a bat or a submarine sonar: it sends out a pulse of sound, waits for the echo to come back, and measures how long that took.

Since we know the speed of sound in air (~343 m/s), we can calculate distance: distance = (time × speed of sound) ÷ 2. We divide by 2 because the sound travels to the object and back.

Trigger (Transmitter)

Emits an ultrasonic "ping" — a short burst of high-frequency sound.

Echo (Receiver)

Listens for the reflected sound wave coming back from the object.

Control Circuit

Measures how long the echo took and outputs the duration to the Arduino.

2. The Distance Formula

The Arduino measures how long the echo took (in microseconds). We use this formula to convert that time into distance:

Distance Formula
distance (cm) = duration × 0.0343 ÷ 2
duration = time for the sound to travel (in microseconds) · 0.0343 cm/µs = speed of sound
Why divide by 2? The sound has to travel to the object AND back. The duration we measure covers both trips. Dividing by 2 gives us just the one-way distance.
3. HC-SR04 Pinout

The HC-SR04 has four pins. It's simple to wire — two for power, and two for the trigger/echo signals.

Pin Connect to Purpose
VCC Arduino 5V Powers the sensor.
Trig Arduino digital pin (e.g., 9) Arduino sends a 10 µs HIGH pulse to start a measurement.
Echo Arduino digital pin (e.g., 10) Sensor sends back a pulse whose length equals the round-trip time.
GND Arduino GND Common ground (essential!).

4. Range & Limitations

The HC-SR04 works best between 2 cm and 400 cm (2 cm to 4 m). Outside that range, readings become unreliable. It also has a 15° measurement cone — meaning it "sees" a cone of space, not just a single point.

Soft or angled surfaces (like foam, cloth, or a wall at 45°) can scatter the sound and give bad readings. For best results, keep the target flat and perpendicular to the sensor.

Range: 2–400 cm

Reliable readings from 2 cm up to about 4 metres in good conditions.

15° Cone

Measures the closest object within a 15-degree cone in front of it.

~60 ms per Read

Don't read too fast — give each measurement about 60 ms to complete.

5. Quick Start — Five Simple Steps

Follow these five steps in order before uploading your code:

  1. Wire the sensor: Connect VCC → 5V, GND → GND, Trig → pin 9, Echo → pin 10.
  2. Mount the sensor: Point it forward, at the same height as the objects you want to detect.
  3. Open the Arduino IDE and paste the code from section 6 below.
  4. Open the Serial Monitor at 9600 baud to see live distance readings in cm.
  5. Test with your hand: Move your hand closer and farther — the readings should change smoothly.
6. Code — Measure Distance on Serial Monitor

Click Copy and paste this into your Arduino IDE. Open the Serial Monitor to see live readings.

ultrasonic_test.ino
/* Ultrasonic Distance Test — HC-SR04 Measures distance and prints it to the Serial Monitor in cm. */ const int trigPin = 9; const int echoPin = 10; void setup() { pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT); Serial.begin(9600); } void loop() { // Send a 10 µs pulse to trigger digitalWrite(trigPin, LOW); delayMicroseconds(2); digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); // Measure how long the echo pin stays HIGH long duration = pulseIn(echoPin, HIGH); // Calculate distance in cm float distance = duration * 0.0343 / 2; Serial.print("Distance: "); Serial.print(distance); Serial.println(" cm"); delay(100); }
How it works: The Arduino sends a short pulse on trigPin, then measures how long the echo pin stays HIGH using pulseIn(). That time is converted into a distance using the speed of sound.
7. Code — Simple Obstacle Avoidance

Combine the sensor with your L298P motor driver to make the robot stop when something is too close.

avoid_obstacle.ino
/* Obstacle Avoidance — HC-SR04 + L298P Robot drives forward until an object is closer than 20 cm, then stops and reverses briefly. */ // Ultrasonic sensor pins const int trigPin = 9; const int echoPin = 10; // L298P motor control pins const int IN1 = 8; const int IN2 = 7; const int IN3 = 6; const int IN4 = 5; const int SAFE_DISTANCE = 20; // cm void setup() { pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT); pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT); Serial.begin(9600); } // Return distance in cm float getDistance() { digitalWrite(trigPin, LOW); delayMicroseconds(2); digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); long duration = pulseIn(echoPin, HIGH); return duration * 0.0343 / 2; } void forward() { digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW); digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW); } void backward() { digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH); digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH); } void stopMotors() { digitalWrite(IN1, LOW); digitalWrite(IN2, LOW); digitalWrite(IN3, LOW); digitalWrite(IN4, LOW); } void loop() { float distance = getDistance(); Serial.print(distance); Serial.println(" cm"); if (distance > 0 && distance < SAFE_DISTANCE) { // Too close — stop, then reverse briefly stopMotors(); delay(300); backward(); delay(500); stopMotors(); } else { // Path is clear — go forward forward(); } delay(60); }
