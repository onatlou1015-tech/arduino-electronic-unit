1. What Is a Microcontroller?

A microcontroller is a tiny computer on a single chip. It contains a CPU, memory, and input/output (I/O) pins — everything needed to read sensors, make decisions, and control electronic components.

Unlike a laptop that runs many programs, a microcontroller is designed to do one job really well — like controlling a microwave, a washing machine, a car's engine, or your Arduino robot. 🤖

CPU

The "brain" that executes your code, one instruction at a time.

Memory

Stores your program (Flash) and temporary data while running (RAM).

I/O Pins

Connect to the outside world — read sensors in, control LEDs and motors out.

2. Arduino Uno Pinout

The Arduino Uno is a popular development board built around the ATmega328P microcontroller. It's the perfect board for beginners because it's easy to program and has clearly labelled pins.

Pin Group Range Purpose
Digital Pins 0 – 13 Read/write HIGH (5V) or LOW (0V). Pins with ~ support PWM.
Analog Pins A0 – A5 Read a continuous voltage from 0–5V (returns 0–1023).
Power Pins 5V, 3.3V, GND Provide power and ground connections to your circuit.
USB Port — Power the board and upload code from your computer.
Reset Button — Restarts your program from the beginning.
3. Digital vs Analog Pins

Understanding the difference between digital and analog signals is key to reading sensors and controlling outputs.

Digital

  • Two states only: HIGH (5V) or LOW (0V)
  • Think of a regular light switch — on or off
  • Pins 0–13 on the Uno
  • Used for: LEDs, buttons, relays

Analog

  • Continuous range: any value from 0V to 5V
  • Think of a dimmer switch or volume knob
  • Pins A0–A5 on the Uno
  • Used for: light sensors, temperature, potentiometers
PWM Tip: Some digital pins (3, 5, 6, 9, 10, 11) have a ~ symbol. They can fake an analog output using PWM — perfect for fading an LED.
4. Breadboard, Resistors & LEDs

A breadboard lets you build circuits without soldering. Inside, metal strips connect rows of holes so you can quickly plug in components and wires.

An LED (Light-Emitting Diode) is a small light that only works when current flows the right way — from the long leg (anode, +) to the short leg (cathode, −).

A resistor limits current so the LED doesn't burn out. We use a 220Ω or 330Ω resistor for a standard red LED at 5V.

5. Quick Start — Five Simple Steps

Follow these five steps in order before you run any code:

  1. Plug in your Arduino to your computer using the USB cable. The green power LED should light up.
  2. Open the Arduino IDE and go to Tools → Board and select Arduino Uno.
  3. Select the port under Tools → Port (it usually says something like COM3 or /dev/ttyUSB0).
  4. Build the circuit on your breadboard: 5V → resistor → LED long leg → LED short leg → GND.
  5. Paste the code below into a new sketch, then click the Upload button (→ arrow icon) to send it to the board.
6. The Blink Code — "Hello World" of Arduino

Click the Copy button to copy the code, then paste it into your Arduino IDE.

blink.ino
/* Blink — Hello World of Arduino Turns an LED on for 1 second, then off for 1 second, forever. */ // The LED is connected to digital pin 9 const int ledPin = 9; void setup() { // Set the LED pin as an output pinMode(ledPin, OUTPUT); } void loop() { digitalWrite(ledPin, HIGH); // Turn LED on delay(1000); // Wait 1 second digitalWrite(ledPin, LOW); // Turn LED off delay(1000); // Wait 1 second }
How it works: setup() runs once at the start. loop() repeats forever. delay(1000) pauses the program for 1000 milliseconds (1 second).
7. Try Faster Blinking

Change the delay values to make the LED blink faster. Try the code below — it blinks every 200 ms.

blink_fast.ino
// Fast blinking LED — 200 ms on, 200 ms off const int ledPin = 9; void setup() { pinMode(ledPin, OUTPUT); } void loop() { digitalWrite(ledPin, HIGH); delay(200); // 0.2 seconds digitalWrite(ledPin, LOW); delay(200); }
