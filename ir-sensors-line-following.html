IR Sensors (Line Following)

Learn how infrared reflectance sensors "see" black and white, calibrate them, and use them to make a robot follow a line.

1. How Do IR Sensors Work?

An infrared (IR) reflectance sensor has two parts: an IR emitter (an invisible LED) and an IR receiver (a photodiode). The emitter shines infrared light down onto the surface, and the receiver measures how much bounces back.

White surfaces reflect most of the IR light → the receiver detects a strong signal.
Black surfaces absorb most of the IR light → the receiver detects very little.

This difference is how your robot knows whether it's over the line or the floor. 🖤🤍

IR Emitter

An infrared LED that shines invisible light onto the surface below.

IR Receiver

A photodiode that measures how much IR light bounces back from the surface.

Comparator

Most modules include a small chip that outputs a clean digital HIGH or LOW signal.

2. Black vs White — What the Sensor "Sees"

Most IR modules output LOW (0) when they detect a black surface, and HIGH (1) on white.

Black Surface

  • Absorbs IR light
  • Little light returns to the receiver
  • Module output → LOW (0) (usually)
  • Means: "I'm on the line"

White Surface

  • Reflects IR light
  • Strong light returns to the receiver
  • Module output → HIGH (1) (usually)
  • Means: "I'm off the line"
Important: Output polarity can vary by module. Always test yours first with the Serial Monitor before writing line-following logic.
3. Digital vs Analog Output

Many IR sensor modules have two outputs: a digital (DO) pin that gives a clean HIGH/LOW signal, and an analog (AO) pin that gives a continuous value depending on surface reflectivity.

For basic line following, the digital output is easier — the module already does the "is it black or white?" decision for you using its onboard potentiometer.

For smoother, more advanced following, use the analog output and compare sensor values in code.

Pin Type Purpose
VCC Power Connect to Arduino 5V.
GND Power Connect to Arduino GND.
DO Digital Output HIGH or LOW depending on surface. Connect to a digital pin.
AO Analog Output Continuous value 0–1023. Connect to an analog pin (optional).
4. Quick Start — Five Simple Steps

Follow these five steps in order before writing any line-following code:

  1. Wire the sensor: Connect VCC → 5V, GND → GND, and DO → Arduino digital pin 2.
  2. Mount the sensor: Place it 5–10 mm above the floor, pointing straight down at the surface.
  3. Open the Serial Monitor: Upload a simple test sketch (next section) to see the sensor values live.
  4. Calibrate: Turn the small potentiometer until the onboard LED turns on over black and off over white (or vice versa).
  5. Record your values: Note the digital HIGH/LOW reading for black and white — you'll use these in your line-following logic.
5. Code — Detect Black Line (Light an LED)

Click Copy and paste this into your Arduino IDE. The onboard LED lights up when the sensor sees black.

detect_line.ino
/* Detect Black Line — IR Sensor Test Lights the onboard LED when the sensor sees a black surface. Watch the Serial Monitor for live readings. */ const int sensorPin = 2; // IR sensor digital output const int ledPin = 13; // Onboard LED void setup() { pinMode(sensorPin, INPUT); pinMode(ledPin, OUTPUT); Serial.begin(9600); } void loop() { int sensorValue = digitalRead(sensorPin); Serial.println(sensorValue); // Most modules: LOW = black detected if (sensorValue == LOW) { digitalWrite(ledPin, HIGH); // Black → LED on } else { digitalWrite(ledPin, LOW); // White → LED off } delay(100); }
How it works: The sensor outputs LOW over black, HIGH over white. The Arduino reads that value and turns the LED on or off accordingly.
6. Code — Simple Two-Sensor Line Follower

With two sensors (left and right), the robot can correct itself when it drifts off the line.

line_follow.ino
/* Two-Sensor Line Follower Left and right IR sensors guide the robot along a black line. Motor pins match the L298P wiring from Week 3. */ // IR sensors const int leftSensor = 2; const int rightSensor = 4; // L298P motor control pins const int IN1 = 8; const int IN2 = 9; const int IN3 = 10; const int IN4 = 11; void setup() { pinMode(leftSensor, INPUT); pinMode(rightSensor, INPUT); pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT); } // --- Motor helper functions --- void forward() { digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW); digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW); } void turnLeft() { digitalWrite(IN1, LOW); digitalWrite(IN2, LOW); digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW); } void turnRight() { digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW); digitalWrite(IN3, LOW); digitalWrite(IN4, LOW); } void stopMotors() { digitalWrite(IN1, LOW); digitalWrite(IN2, LOW); digitalWrite(IN3, LOW); digitalWrite(IN4, LOW); } void loop() { int left = digitalRead(leftSensor); int right = digitalRead(rightSensor); // Both on black → go straight if (left == LOW && right == LOW) { forward(); } // Left off line → turn left else if (left == HIGH && right == LOW) { turnLeft(); } // Right off line → turn right else if (left == LOW && right == HIGH) { turnRight(); } // Both off line → stop else { stopMotors(); } }
